PLAYTV WebGPU diagnostics update

This change improves diagnosis; it does NOT force-enable WebGPU and does NOT claim to fix game compatibility.

The Legacy launcher now separately reports:
- whether navigator.gpu is exposed by the installed WebView;
- whether requestAdapter() returns an adapter;
- whether requestDevice() succeeds;
- WebGL 1 / WebGL 2 availability and optional renderer information.

Removed the incorrect assertion that missing navigator.gpu proves the hardware lacks Vulkan 1.1 compute. Android's advertised Vulkan features and installed Vulkan driver do not guarantee WebGPU is exposed or usable by Amazon WebView.

Target device reported by the user: MediaTek MT8695, Fire OS 7 / Android 9 (API 28), Amazon Chromium WebView 138. The user reported Android feature flags for Vulkan compute/level and Vulkan version 0x00400400 (Vulkan 1.3.0), plus /vendor/lib/hw/vulkan.mt8695.so. These are platform-reported signals, not a successful WebGPU test.

Build verification: not run in this environment; run the Legacy GitHub Actions workflow and test the GPU Diagnostics tab on the actual Fire TV.
