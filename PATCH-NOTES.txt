PLAYTV source replacement package

- Updated both app variants to read platform and artwork fields from games.json.
- Added platform-based shelves and platform-aware search.
- Changed game cards to use cover-style artwork rather than only small favicons.
- Artwork lookup prefers an explicit catalog art URL, then Open Graph/Twitter image metadata, then a site favicon fallback.
- Updated both 38-entry game catalogs.
- Keeps app/ as the legacy Android WebView variant and app-chromium/ as the bundled Chromium variant.
- WebGPU availability depends on the Chromium engine, Android device/driver, and the target website; artwork/catalog changes do not add WebGPU support.
- Source has not been compiled or tested in this environment. Use the repository GitHub Actions workflow to build and check both APK variants.
